- Fix the adaptive-resolution compile crash caused by persisted summaries with null `sourceIds`. On load, the loader keeps a summary's content when it can recover the source ids and range from a readable duplicate or an L1's compressed chunk record. Strings, empty source lists, and lists containing non-id values are also repaired or dropped because readers expect message or summary ids. The loader drops unrecoverable and empty-content summaries, then drops every ancestor that names one. It unmerges surviving children, reopens chunks whose L1 was dropped, and removes queued merges naming dropped summaries. Repaired state is persisted, and the log names rebuilt and dropped summary ids. Malformed queue entries and unreadable source lists are rejected even in audit-only mode. Live persisted-L1 lookups skip non-array sources.
