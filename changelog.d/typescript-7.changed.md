- context-manager builds and typechecks with TypeScript 7 (`^7.0.2`, a devDependency). The published `.js` is unchanged; a few `.d.ts` files differ only in the quote style of string-literal types, and source maps differ in their `mappings`. A build now needs TypeScript 7's native compiler for the platform: one of its optional `@typescript/typescript-<os>-<cpu>` packages, which npm installs where TypeScript publishes one. So neither a checkout nor a git dependency's `prepare` builds on a platform with none, and a checkout installed without optional dependencies (`npm ci --omit=optional`) fails in its `prepare` build. A git dependency still builds under an outer `--omit=optional`, since npm installs its dependencies with optional ones included before its `prepare` runs. Installing the published package is unaffected.
