- context-manager builds and typechecks with TypeScript 7 (`^7.0.2`, a devDependency). The published `.js` is unchanged; a few `.d.ts` files differ only in the quote style of string-literal types. Building from a checkout, including the `prepare` build of a git dependency, now needs TypeScript 7's native compiler for the platform: one of its optional `@typescript/typescript-<os>-<cpu>` packages, which npm installs where TypeScript publishes one. Such a build fails on a platform with none, or when optional dependencies are skipped (`--omit=optional`). Installing the published package is unaffected.
