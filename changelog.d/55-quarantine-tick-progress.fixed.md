- Maintenance ticks skip quarantined chunks to reach eligible compression or merges. Each tick visits its initially queued source identities at most once, using current queue entries after rebuilds. The scan yields between quarantine checks so inbound events can run. Attempted work still consumes the tick. A chunk a tick skipped is ordered behind the chunks and merges that haven't failed, as a failed chunk is, so the rebuild that every inbound message makes doesn't build its request ahead of them. The strategy warns once per skipped source identity on each branch it loads. Quarantine-family matching is unchanged; the retry policy's changes are in the transient-ladder entry.
