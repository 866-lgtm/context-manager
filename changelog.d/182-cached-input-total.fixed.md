- A compression attempt's provider input count adds cache writes and cache reads to `inputTokens` for every provider, not only for Anthropic and Bedrock (#182). membrane states those three counts as disjoint wherever it knows the convention, so on the other providers that report cache reads, OpenAI's adapters, OpenRouter and, from membrane 0.6.0, Gemini, the count left out the cached span. A refused or incomplete compression's fallback plan then took a baseline too small, and could send an expanded fallback that doesn't fit the compression budget instead of recording it as `admission_rejected`. A successful attempt's `renderedTokens` under-reported its prompt by the same span.
  - **Host operators:** on those providers, a fallback that doesn't fit is now `admission_rejected` and not sent, as on Anthropic and Bedrock, and `renderedTokens` includes the cached span. A full cache hit, no fresh input beside a positive cache read, now counts as the provider's count of the prompt there too, where before the complete request bound stood in for it.
  - Quarantine records written before this release go on holding their chunks, and the upgrade releases none. On OpenAI's adapters or OpenRouter, or on Gemini through membrane 0.6.0, the old count may have planned a held chunk's fallbacks wrongly, so the chunk may compress now: clearing its quarantine with `clearCompressionRefusalQuarantine` gives it a fresh attempt under the corrected count.
  - The `@animalabs/membrane` range is `^0.6.0`, the first release that states Gemini's cached input apart from its fresh input (antra-tess/membrane#109). It also adds Gemini's tool-use prompt tokens, which Google's own tools such as code execution add to a prompt, to the input count (antra-tess/membrane#125). The strategy counts through `ctx.membrane`, the host's instance, so a host must take 0.6.0 or later in its own `@animalabs/membrane` range too. A host whose membrane is older passes Gemini's counts raw, and before 0.5.81 OpenAI's too, with the cached span inside the input count, so the sum counts that span twice, and a fallback that fits can be `admission_rejected`.
